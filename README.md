# UIM Progression Guide

A step-by-step progression guide for **Old School RuneScape Ultimate Ironman**, written for players who want to get from the first tick to the max cape with the fewest trips, slots and risky deaths.

**Read it online:** https://uimguide.github.io/uim-guide/

## Purpose

Most Ultimate Ironman routes assume you can use a bank. This guide does not. It is built around comfort and safety:

- No tick manipulation outside the fast track in Chapter 4.
- The fewest trips, inventory slots and risky deaths.
- Training that quest XP would give you later is left to the quests, so you do not train the same skill twice.

The early route is an independent rewrite for Ultimate Ironman, inspired by the BRUHsailer Ironman guide by So Iron BRUH and ParasailerOSRS.

## Chapters

| Chapter | Covers | Tasks |
|---|---|---|
| 1 | Tutorial Island to Desert Treasure | 321 |
| 2 | The long quest blocks to Song of the Elves | 305 |
| 3 | Song of the Elves to the quest cape | 134 |
| 4 | The quest cape to the max cape | 31 |

Each chapter is split into blocks. Every block lists its steps and the wiki pages it relies on, and Chapter 4 offers a fast track and an easier option for each skill block.

## Site features

- **Tick off steps.** Progress is saved in this browser only.
- **Continue where I left off**, and **Reset chapter** (it asks before clearing) on each chapter page.
- **Hide finished** steps and blocks from the contents sidebar, which also follows your place as you scroll.
- **Export and import progress** as a small JSON file, to move it to another browser or device.
- **Search** quests, items and levels. Press `/` to jump to the search box; arrow keys move through the results.
- **Light and dark themes**, a layout that works at half-screen beside the game client, and keyboard and screen-reader support (skip link, visible focus, reduced motion).

## Accuracy and sources

Mechanics are checked against the [Old School RuneScape Wiki](https://oldschool.runescape.wiki/), and every block links the wiki pages it relies on. The links were last checked on 23 November 2026.

A few points still need checking in game, such as Mastering Mixology hopper behaviour after logout and barrage XP per damage. Reports from playing the guide are welcome.

## Running it locally

The site is plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or serve the folder with any static file server.
